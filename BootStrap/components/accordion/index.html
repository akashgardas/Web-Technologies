Accordion

This is an Accordion

Classes Used:
  • accordion
  • accordion-item
  • accordion-header
  • accordion-body
  • accordion-collapse
  • accordion-button

data bs required:
  • data-bs-target - Used in the button of the accordion header. It points to the accordion-collapse element's ID
  • data-bs-toggle- Used in the button of the accordion header to toggle the collapse from the accordion body
  • data-bs-parent- Used in the accordion-collapse element to achieve the functionality of only one accordion opens at a time. It points to the ID of the parent accordion container
